# Active Wind Power Forecasting Through Machine Learning

## 📌 Project Overview

This project focuses on forecasting wind power generation using machine learning techniques and wind turbine sensor data. The system uses parameters such as wind speed, temperature, rotor speed, and power output to predict wind power generation accurately.

The project includes data preprocessing, exploratory analysis, feature preparation, machine learning model development, and performance evaluation.

## 🎯 Objectives

* Analyze wind turbine sensor data.
* Handle missing values and outliers.
* Perform data preprocessing and normalization.
* Develop machine learning models for wind power forecasting.
* Compare different machine learning algorithms.
* Identify the best-performing model using evaluation metrics.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Django

* CSS

## 🤖 Machine Learning Models

The following models were implemented and compared:

* K-Nearest Neighbors (KNN)
* Linear Regression
* Lasso Regression
* Decision Tree

## 📊 Evaluation Metrics

The models were evaluated using:

* MAE — Mean Absolute Error
* MSE — Mean Squared Error
* RMSE — Root Mean Squared Error
* MAPE — Mean Absolute Percentage Error
* R² Score — Coefficient of Determination

## 🏆 Result

After comparing the different machine learning models, **KNN achieved the best forecasting performance** based on the evaluation results.
